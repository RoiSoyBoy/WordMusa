- Album art color gradient: fixed two sequential bugs — ImageManipulator can't read remote URLs (must download first via FileSystem), and `expo-file-system` v55 deprecated `downloadAsync` (fix: import from `expo-file-system/legacy`)
- PlaybackControls: changed background to `theme.colors.surface` + top border to visually separate controls from lyrics

## What broke and why
- Gradient silent failure: `extractAlbumColor` swallowed all errors — added targeted console.logs to locate each failure
- `ImageManipulator.manipulateAsync` throws on remote HTTPS URLs — only accepts local file:// URIs
- `FileSystem.downloadAsync` deprecated in expo-file-system v55 — needs `/legacy` import path

## Decisions made
- Keep pure-JS color extraction (download → ImageManipulator → pako) rather than moving to backend — works now with legacy import
- SafeAreaView padding bug in Modal: wrap content in plain View for reliable padding instead of fighting SafeAreaView
