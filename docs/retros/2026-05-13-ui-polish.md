## What broke and why
- LRC files contain lines with just `'` (apostrophe used as pause marker in some tracks)
- `parseLRC` only filtered empty strings — `'` is truthy, so it passed through
- GPT received `'` as a lyric line, returned `'` as its translation (correct behavior for GPT, wrong for us)
- Fix: added `!/[a-zA-Z]/.test(text)` guard to require at least one letter per line

## Decisions made
- Opacity on the lyric container `Pressable`, not on `Text` — lets the touch target stay full-size
- `lyrics_cache` write rule kept as `create: authenticated` (frontend writes on LRCLIB cache miss)
